# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/idevsoftwaregroup/i-dev.git
```

Navigate into project:

```bash
cd i-dev
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
